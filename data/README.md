# Data Folder Instructions

This folder is intentionally left empty because the datasets used in this project are very large.

Please download the following required dataset files manually from the NASA Earth data portals:

- `GLDAS_NOAH025_3H_EP.A20240601.0000.021.nc4`
- `GLDAS_VIC10_M.A194801.020.nc4`
- `GRACEDADM_CLSM025GL_7D.A20240527.030.nc4`
- `MERRA2_400.inst3_3d_asm_Np.20240901.nc4`
- `MYD28C3.A2024153.061.2024274192502.hdf`
- `NLDAS_NOAH0125_M.A197901.020.nc`

You can download these datasets from:

- [NASA GES DISC](https://disc.gsfc.nasa.gov/)
- [NASA Earthdata Login](https://earthdata.nasa.gov/)

**Note:** An Earthdata account is required to access and download these files.

---

Please place the downloaded files in this `data/` directory to enable the scripts and visualizations to run correctly.
